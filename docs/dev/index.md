# dev 實作文件

**這個資料夾放實作文件，跟著程式碼一起長。**
現在還沒有程式碼，所以這裡只有這一份說明。

## 角色

- 規格階段：[`../tw/`](../tw/index.md) 是規格的唯一真實來源，這裡是空的。
- 程式碼出現後：實作行為以這裡為準。這裡和 `tw/` 衝突時，先判斷是 bug 還是規格演進，是規格演進就回頭更新 `tw/`。
- 開發完成後：`en/` 和 `tw/` 退場封存，只留這裡。

## 寫作規則

**文件跟著程式碼走，越少越好。**

- 只寫程式碼本身講不清楚的事：架構決定、跨模組流程、部署方式、環境需求。
- 具體指出檔案路徑、指令、設定位置。
- 不複製 `en/` 那套每模組五個檔的形式。一個主題一份文件，夠用就好。
- 型別和介面以程式碼為準，不維護契約編號表。
- 新增文件時，同步更新本檔和 [`../index.md`](../index.md) 的清單。

- NetBird 實證的證據紀錄和 fixture 位置。
- backend 專案結構和啟動方式。
- 資料庫 migration 的操作說明。
